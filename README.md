# Rogue Side

Game prototype 2D Action Roguelike Side-Scroller berbasis Godot 4 + GDScript.

Fitur utama:
- Player bergerak cepat dan responsif
- Dash, jump, combo attack, kemampuan aktif
- Sistem enemy AI dasar
- EventBus untuk komunikasi antar sistem
- Struktur modular untuk pengembangan roguelike lebih lanjut

Struktur folder:
- scenes/
- scripts/
- project.godot

Cara membuka di Godot:
1. Buka Godot Engine 4.x
2. Pilih Open Project
3. Arahkan ke folder repositori ini
4. Tekan Run

Catatan:
Project ini adalah skeleton siap dikembangkan menjadi game penuh. Anda bisa langsung menambahkan room generator, item system, boss, UI, dan run progression.
